# OmniShield AI — Frontend Demo

A standalone HTML/CSS/JavaScript frontend with a cinematic login-to-dashboard transition and a glossy sapphire / midnight-blue visual theme.

## Run it
1. Extract this ZIP.
2. Open `frontend-demo/index.html` in a modern browser, or use VS Code Live Server.
3. Submit the demo login form to see the O → S logo transition and dashboard.

## Important
This is a frontend demo. Login is simulated and dashboard values are sample data; this package does not connect to or authenticate against your backend. Connect the login form and dashboard API calls to your real backend before deployment.


### Home-screen installation
The frontend is now installable as a PWA when served over HTTPS (or localhost). Chromium browsers show an **Install app** action when installation criteria are met; on iOS, use Safari Share → Add to Home Screen. See the root README for offline and security limitations.
